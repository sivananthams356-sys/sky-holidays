# Sky Holidays – Spring Boot + MySQL

1. Install JDK 17 and IntelliJ IDEA Community (or Maven).
2. MySQL Workbench: File > Open SQL Script > schema.sql > click the lightning icon.
3. Edit src/main/resources/application.properties (MySQL password, admin email + password).
4. Run SkyHolidaysApplication (IntelliJ green play button) or: mvn spring-boot:run
5. Open http://localhost:8080 and log in with the admin email/password from application.properties.
